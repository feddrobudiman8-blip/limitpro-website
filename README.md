# 🚀 LimitPro Website

A modern full-stack business website developed for **LimitPro Indonesia**.

This project combines a responsive frontend with a Node.js backend and visitor analytics system. It was built as part of my web development learning journey and portfolio.

---

## 🌐 About the Project

LimitPro Website is designed to provide a modern and responsive online presence for LimitPro Indonesia.

The website includes business information, interactive sections, and a visitor tracking system connected to a backend server and database.

---

## ✨ Features

- 📱 Responsive website design
- 💻 Modern user interface
- ⚡ Interactive JavaScript functionality
- 📊 Visitor analytics system
- 👥 Total visitor tracking
- 🟢 Online visitor tracking
- 🔢 Unique visitor tracking
